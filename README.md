Program description:
This program is a student ID card generator running in the console. 
It requests several personal information from the user, performs some calculations
(like graduation year, student age), and then displays a formatted student card. 
The program uses variables, the 4 basic types, more than 10 inputs, f-strings
and a clear final summary in accordance with the project requirements.
